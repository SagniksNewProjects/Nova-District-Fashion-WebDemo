# NOVA DISTRICT — Fashion Design Website Demo
NOVA DISTRICT is a modern fashion-brand website built around a minimalist editorial aesthetic. The design combines oversized typography, high-impact fashion photography, asymmetric layouts, generous whitespace, and a monochrome palette with a distinctive red accent.

NOVA DISTRICT — Fashion Website Demo

This website is designed around a fictional fashion brand intended for personal and demonstrative usage.
The NOVA DISTRICT brand identity, content and design concept are strictly FICTIONAL.
